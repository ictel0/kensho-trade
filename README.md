# 検証ラボ（サイト雛形）

静的サイトの雛形。ビルド不要のプレーンなHTML/CSSのみ。未デプロイ・未公開。

- サイト名「検証ラボ」は仮称（ドメイン・正式名称は未決定）。
- コンセプト：手法を固定ルールで測り、悪い結果も含めて全部載せる検証サイト。

## 検証ページの追加方法

1. `articles/` 内の既存ページを1つコピーし、ファイル名を手法のスラッグにする（例：`articles/usdjpy-fade.html`）。
2. 中身を差し替える。**書式は固定**で、次の5節を必ずこの順で置く：
   1. ルール定義（エントリー・決済・再武装条件まで、後付け解釈が入らない粒度で）
   2. データと条件（対象・足型・期間・件数・コスト前提を表で）
   3. 結果（表。期待値・勝率・件数は必須。数字には期間と件数を添える）
   4. 悪い点・留保（後半期間の悪化、含み損、バイアスなど。無い場合は「なし」とは書かず、検証の限界を書く）
   5. 判定（監視中／却下／優位性なし 等を `.verdict-box` で明示）
3. 以下は全ページ必須（コピー元に含まれているので消さない）：
   - 冒頭のPR表記ブロック（`.pr-note`、ステマ規制対応）
   - フッターの免責（過去の検証結果は将来を保証しない／投資助言ではない）
   - アフィリエイトリンク枠は `<!-- AFFILIATE: ... -->` のプレースホルダで置き、実リンクは提携確定後に差し込む
4. `index.html` の検証記事一覧にカードを1枚追加する（結果の1行サマリと判定バッジ付き）。
5. 相対パスに注意：`articles/` 内のページは `../style.css`、`../index.html` を参照する。

## 判定バッジのクラス

- 監視中：`verdict verdict-watch`
- 却下：`verdict verdict-reject`
- 優位性なし：`verdict verdict-none`
